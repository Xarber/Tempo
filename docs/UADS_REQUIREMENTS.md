# Tempo UADS requirements

The baseline is the supplied standards through section 52. No upstream
version number was provided. The registry assigns stable Tempo IDs to section
groups. Keep these IDs when adding individually verifiable requirements.

Read the root manifest before substantive changes. For each affected
requirement record the commit, execution date, target platform, result and
evidence under docs/reports/compliance or link to the exact CI run. A pending
section group can contain some verified checks. Require evidence for every
applicable check before marking the group passed.

Backend endpoint switching is currently inapplicable because Tempo runs
locally. Automatic native publication and alternative distribution depend on
authorized signed releases. The registry currently provides section-level
traceability. Individually testable coverage is still being expanded.
